# UK Wind Forecast Dashboard

Measures how accurate Great Britain's national wind forecasts (Elexon BMRS WINDFOR) are against recorded generation (FUELHH `WIND`) for January 2026. See `README.md` for the full design and API.

Stack: TimescaleDB (PostgreSQL 17) · FastAPI + Pandas · React 19 + TypeScript + Vite · Docker Compose.

## Commands

```bash
./run.sh              # production-like stack: frontend :3000, API :8000
./run.sh --dev        # hot reload: Vite :5173, uvicorn --reload (bind-mounted source)
./run.sh --stop       # stop containers, keep database
./run.sh --logs

docker compose run --rm backend pytest                 # backend tests (need the db service up)
cd frontend && npm test                                # vitest
cd frontend && npm run lint && npx tsc -b              # oxlint + type check
```

Backend tests need the `db` service (`docker compose up -d db`). Rebuild with `./run.sh --build` after dependency changes.

## Rules that matter

- **Test first.** A hook in `.claude/` blocks writes to `backend/app/**` and `frontend/src/**` source files that have no test. Write the test before the code. See `docs/guidelines/testing.md`.
- **Data flows one way.** Only `app/ingest` calls Elexon. API requests read the database and never download.
- **Layering:** `repository.py` = SQL, `analysis.py` = pure Pandas, `dashboard.py` = response shaping, `api/` = thin handlers.
- **The horizon rule lives only in `app/services/horizon.py`.** Do not re-implement it elsewhere.
- **Missing data is a gap, never zero.** Excluded from metrics and counted in the coverage note.
- **Times:** store UTC; Europe/London helpers live in `app/timezones.py` and `frontend/src/lib/time.ts`.
- Pin dependency versions exactly (see `pyproject.toml`).
- Do not commit `.env`. Do not edit `components/ui/` by hand; it is generated by shadcn.
